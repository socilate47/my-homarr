# Make it mine

Discovery fills the board with useful links. The layout, names, icons and background are mine to choose.

## My names and icons

Edit an app to give it a familiar name. Use the icon picker to upload an image or choose an existing icon. Discovery preserves that name and icon when the guest reports again.

Drag tiles into the arrangement that makes sense for the lab. Reports keep their positions. If I change an app URL manually, that URL stays as my override.

## My background

Open Board settings → Background to upload an image, MP4 or WebM video. Uploads support files up to 32 MB.

Video wallpapers loop silently. Use the wallpaper control to pause or resume them. They pause while the page is hidden and respect reduced-motion preferences unless I explicitly choose to play.

## Removed and offline services

Removing a discovered tile keeps it removed. Use Restore tile in Discovery when it should return, including when its guest is offline.

Missing or offline guests keep their inventory and existing shortcuts. Losing a heartbeat does not erase a customized dashboard.

## Moving discovery to another board

Changing the destination keeps the existing tiles on the previous board. New services use the new destination. Restore an existing service from Discovery to add it there too.

For the general board settings, use the [dashboard reference](/docs/management/boards).
