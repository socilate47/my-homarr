# Media
Using the media feature, you can upload images for custom icons to Homarr.
Images will be stored in the database. They can be selected in the [icon picker](/docs/advanced/icons).

![](./img/screenshot.png)
## Background images and videos

Media uploads also support MP4 and WebM video backgrounds, up to 32 MB per file. Choose an uploaded video from **Board settings → Background** to use it as a silent looping wallpaper. Use the wallpaper control to pause playback. Videos do not appear in the icon picker, which remains image-only.
